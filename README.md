# CEH Field Manual

A self-contained study hub for the Certified Ethical Hacker (CEH) exam: a 12-week
plan, plain-language notes on all 20 modules, command cheat-sheets, a port
reference, free practice-lab links, and a practice quiz. Progress is saved in
your browser.

**Live site:** https://samiullahsaleem.github.io/ceh-field-manual/

These are original study notes written from the public CEH exam objectives — not a
copy of any course's videos or materials. Use them to review alongside your own
course and your own notes.
