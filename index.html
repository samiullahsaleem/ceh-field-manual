Build your practice lab (Week 1)

  • 🖥️ Virtualization: VirtualBox or VMware (free Workstation Player).

  • 🎯 Targets: Metasploitable 2/3, OWASP Juice Shop, a Windows eval VM.

Command cheat-sheets

The exact syntax you'll run in the labs and recognize in exam screenshots. Replace <ip> and wordlist paths with your own. Run these only against your lab or iLabs.

Nmap

Scanning & recon
nmap -sS -sV -O <ip>Stealth SYN scan + service versions + OS guess
nmap -p- <ip>All 65,535 TCP ports
nmap -sU --top-ports 50 <ip>Top 50 UDP ports
nmap -A -T4 <ip>Aggressive: scripts, version, OS, traceroute
nmap -Pn <ip>Skip host discovery (treat host as up)
nmap -f -D RND:5 -T1 <ip>Evasion: fragment + decoys + slow

Enumeration

SMB · SNMP · DNS
enum4linux -a <ip>Full SMB/NetBIOS enumeration
smbclient -L //<ip> -NList shares using a null session
snmpwalk -v2c -c public <ip>Walk SNMP with the default community
dig axfr @<ns> target.comAttempt a DNS zone transfer
nbtstat -A <ip>NetBIOS name table (Windows)

Password cracking

Online & offline
hydra -l admin -P rockyou.txt ssh://<ip>Online brute-force of SSH login
john --wordlist=rockyou.txt hashes.txtOffline dictionary crack
hashcat -m 1000 -a 0 hash.txt rockyou.txtCrack NTLM (-m 0 = MD5)
hashid '<hash>'Identify the hash type first
# Hydra = online · John/Hashcat = offlineClassic exam distinction

Exploit & post-exploit

App testing

Capture & MITM

Exam readiness

EXAM

CEH (ANSI) at a glance

The multiple-choice exam is 125 questions in 4 hours. The passing score isn't fixed — it shifts with question difficulty (roughly 60–85%). Questions are scenario-based: you pick the best next step, the right tool, or read a tool's output.

Score big on these

  • The 5 hacking phases — in order, every time.
  • Which tool does what (Nmap flags, Hydra, sqlmap, Aircrack-ng, Wireshark).
  • Reading Nmap & packet output in a screenshot.
  • Scan types & TCP flags (SYN, ACK, FIN, NULL, Xmas).
  • Crypto: symmetric vs asymmetric, hashing, PKI.

Prep in Week 12

  • Take timed practice tests until you clear ~80% consistently.
  • Redo every lab you marked unsure.
  • Memorize port numbers & common CVEs.
  • Consider the practical CEH (Practical) exam after — 6 hours, real challenges.
  • Sleep. A rested brain beats one more cram session.
